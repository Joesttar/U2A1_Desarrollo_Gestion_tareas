Gestor de Tareas en Python (U2 A1)

Aplicación de consola desarrollada en Python para la gestión de tareas universitarias, implementando patrones de diseño, persistencia de datos y pruebas unitarias.

## Funcionalidades
- Agregar nuevas tareas pendientes.
- Listar todas las tareas registradas con su estado (Pendiente / Completada).
- Marcar tareas como completadas.
- Persistencia automática de datos mediante un archivo JSON (`tasks.json`).
- Implementación del patrón de diseño **Singleton** para la gestión de la configuración global (modo debug).

## Requisitos
- Python 3.x instalado en tu sistema.

2. Abre tu terminal en la carpeta del proyecto.
